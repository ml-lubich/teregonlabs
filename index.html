BRIOBOT / SUPPORT OPERATIONS

BrioBot case triage

Salesforce case context, evidence retrieval, and a draft action.

Company-level ARR context reported by the team: approximately $240K at the time. This revenue is not attributed to BrioBot.

For e-commerce support, a LangGraph flow gathers case context, retrieves product and policy evidence, reads attached images, and drafts structured actions. Deterministic Python gates validate writable fields; dry-run and safe-stop paths keep Salesforce updates explicit, with Langfuse traces for review.

BRIOPEDIA / KNOWLEDGE SYSTEMS

Briopedia knowledge system

One maintained source for search and support chat.

Company-level ARR context reported by the team: now approximately $2M. This revenue is not attributed to Briopedia.

A Next.js library with a FastAPI backend pairs a git-versioned wiki with FAISS retrieval and provider-agnostic local or cloud LLM chat. Replies use retrieved source material; the wiki keeps an editable, reviewable history.

MEASURING THE WORK

How we measure
results.

We agree on a baseline, then track a result the client can verify, such as resolution time, repeat contacts, or forecast accuracy.

01 / BEFORE

Set the baseline

Agree what the team measures today and where reliable evidence lives.

02 / DURING

Connect the data

Bring the relevant data into a view people can use to make the next decision.

03 / AFTER

Verify the change

Compare against the baseline. Publish a result only when the client has verified it.
